Six-agent governance for autonomous USDC payments

A multi-agent system built on Circle Agent Stack that governs how AI agents spend USDC. Every payment flows through Circle Agent Wallets, gets policy-checked by our 6-agent system, and settles on Base.

Circle Agent Stack Integration
Agent Wallets
2-of-2 MPC custody. Key shares never exposed to agents. Spending policies (per-tx caps, daily limits, recipient allowlists) enforced at the wallet layer before on-chain submission.
x402 Protocol
HTTP 402 payment protocol. Agent sends request, gets 402 challenge, signs EIP-3009 authorization, retries with payment. Used by circle services pay.
Agent Marketplace
Machine-readable service discovery at agents.circle.com. Agents find, evaluate, and pay for services autonomously via circle services search.
Defense-in-Depth: Verigate + Circle
Layer 1: Verigate Gate
Deterministic policy evaluation (zero LLM)
Ed25519 signed receipts for every decision
60s single-use token (JTI = Circle idempotency key)
6-agent governance system (investigate, recommend, isolate)
Layer 2: Circle Wallet Policies
Per-transaction USDC caps
Daily / weekly / monthly spending limits
Recipient allowlists and blocklists
Sanctions screening on every transfer
Even if Verigate is bypassed, Circle's wallet policies independently enforce spending limits.
