Circle Agent Stack Integration
Agent Wallets
2-of-2 MPC custody. Key shares never exposed to agents. Spending policies (per-tx caps, daily limits, recipient allowlists) enforced at the wallet layer before on-chain submission.

HTTP 402 payment protocol. Agent sends request, gets 402 challenge, signs EIP-3009 authorization, retries with payment. Used by circle services pay.

Machine-readable service discovery at agents.circle.com. Agents find, evaluate, and pay for services autonomously via circle services search.
